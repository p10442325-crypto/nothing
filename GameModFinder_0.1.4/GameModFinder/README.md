# Pawchive Mod Finder v2

Pawchive에서 원하는 크리에이터를 찾아 팔로우하고, 게시물을 모아 보고, 첨부 파일을 직접 다운로드하는 Windows 데스크톱 앱입니다.

> 이 프로그램은 모드 탐색·열람·다운로드 도구입니다. 설치된 모드 관리 프로그램이 아닙니다.

## 실행 방법 (Windows)

1. Python 3.10 이상을 설치합니다. https://www.python.org/downloads/windows/
2. Google Chrome 또는 Microsoft Edge를 설치합니다. Python 연결이 Windows에서 끊기는 경우 설치된 브라우저로 다시 연결합니다.
3. ZIP 파일을 내려받아 압축 해제합니다.
4. `GameModFinder` 폴더 안의 `run.bat`을 더블클릭합니다.
5. 첫 실행은 가상환경과 Python 패키지를 자동으로 설치합니다.

## 화면

- **팔로잉**: 팔로우한 크리에이터의 최신 게시물을 모아 보기. 직접 새로고침과 60분 기본 자동 동기화 지원.
- **크리에이터**: 팔로우 목록과 크리에이터별 게시물 보기.
- **크리에이터 찾기**: Pawchive 프로필 URL 또는 서비스 + 크리에이터 ID로 추가.
- **전체 탐색**: 캐릭터 이름·영문 별칭으로 검색. 제목과 내용 검색 범위를 각각 켜고 끌 수 있으며, 압축파일 첨부 게시물만 표시.
- **제작자 후보**: 캐릭터 이름·영문 별칭을 여러 개 입력하면 게시물을 페이지별로 자동 검색하고, 첨부 압축파일을 임시 검사합니다. 내부에서 INI가 발견된 게시물의 작성자를 모아 보여주며 근거 게시물과 프로필을 다시 열 수 있습니다.
- **게시물 보기**: 본문 서식(HTML/Markdown)을 살려 표시하고, 이미지 첨부는 Pawchive 썸네일을 불러와 미리보기.
- **다운로드**: 게시물 첨부 파일을 앱에서 다운로드하고 다운로드 기록 확인.
- **설정**: 공통 저장 폴더, 게임별 저장 폴더, 동기화 간격 설정. GitHub 업데이트 확인 및 앱 종료 후 자동 적용·재시작 지원.

## 프로그램 업데이트

설정 탭의 **업데이트 확인** 버튼으로 GitHub의 최신 버전을 확인할 수 있습니다. 새 버전이 있으면 앱 안에서 업데이트 파일을 내려받고, **업데이트 적용 후 재시작**을 누르면 앱 종료 후 파일을 교체하고 자동으로 다시 실행합니다.

- 업데이트는 이 저장소의 `feature/pawchive-mod-finder-v2` 브랜치에서 확인합니다.
- 업데이트 중에도 `.venv`와 사용자 데이터 폴더(`%APPDATA%\\PawchiveModFinder`)는 보존합니다.
- 업데이트 파일은 임시 폴더에서 검사·압축 해제한 뒤 적용하며, 적용에 실패하면 기존 앱 파일을 복원합니다.
- 업데이트를 확인하거나 내려받는 동안에는 진행 중인 다운로드·게시물 작업을 먼저 마쳐야 합니다.
- 업데이트 확인에는 인터넷 연결이 필요합니다. GitHub에 접속할 수 없으면 기존 설치본은 그대로 유지됩니다.

## 저장과 압축 해제

- 다운로드 위치는 공통 폴더 또는 사용자가 지정한 게임별 폴더 중에서 다운로드마다 선택합니다. 선택한 기준 폴더에 바로 저장하거나 그 안의 하위 폴더를 골라 저장할 수 있습니다. 자동 게임 판별은 하지 않습니다.
- ZIP 및 TAR 계열 파일은 다운로드 후 안전 검사를 거쳐 자동 압축 해제합니다.
- 기존 파일은 덮어쓰지 않습니다. 압축 파일의 경로 탈출과 심볼릭 링크는 차단합니다.
- 지원하지 않는 압축 형식은 원본 파일로 보관합니다.

## 데이터 위치

설정과 SQLite 데이터베이스는 사용자 데이터 폴더에 저장됩니다.

- Windows: `%APPDATA%\PawchiveModFinder\`
- 설정: `settings.json`
- 데이터베이스: `pawchive.sqlite3`

## Pawchive API와 다운로드

기본 API 주소는 `https://pawchive.pw/api/v1`, 원본 파일 호스트는 `https://file.pawchive.pw/data/...`, 이미지 미리보기는 `https://img.pawchive.pw/thumbnail/data/...` 입니다. API 요청에는 계정 쿠키를 보내지 않습니다. **파일과 이미지 요청에는 브라우저를 흉내 내는 User-Agent를 사용하지 않습니다.** 프로젝트 주소를 포함한 앱 식별 User-Agent, HTTP/1.1, 초당 1회 연결 제한, 파일명 `f` 파라미터를 사용해 `curl.exe`로 전송하며, Windows의 IPv6 경로 문제를 피하도록 IPv4를 먼저 시도합니다. curl TLS 연결이 계속 끊기면 설치된 Chrome 또는 Edge를 대체 TLS 전송 계층으로 사용하되, 요청 User-Agent는 계속 앱 식별자로 유지하고 HTTP/2·QUIC은 끕니다. 376바이트 반응은 서버의 자동 요청 제한으로 판별해 파일로 저장하지 않습니다. 설정한 선택적 세션 키는 파일/이미지 요청에만 사용됩니다.

## 검색 범위와 자동 제작자 후보 탐색

전체 탐색과 제작자 후보 자동 탐색에서 **제목**과 **내용** 검색 범위를 각각 선택할 수 있습니다. 두 항목을 모두 선택하면 둘 다 검색하고, 하나만 선택하면 서버 검색 결과에서 선택하지 않은 필드에만 일치하는 게시물을 제외합니다.

**제작자 후보** 탭에 캐릭터 이름이나 영문 별칭을 쉼표·세미콜론·줄바꿈으로 구분해 입력하고 **후보 제작자 자동 탐색**을 누르면 다음 작업을 자동 수행합니다.

1. 입력한 검색어마다 Pawchive 게시물을 최대 지정 페이지 수만큼 검색합니다(기본 5페이지, 검색어당 최대 250개 게시물).
2. 제목/내용 검색 범위를 적용하고 압축파일 첨부 게시물만 추립니다.
3. ZIP, 7Z, RAR, TAR 계열 압축파일을 임시 폴더에 내려받아 내부 파일 이름에서 `.ini` 항목을 검사합니다.
4. INI가 발견된 게시물의 작성자를 중복 제거해 후보 목록에 추가하고, 근거 게시물·압축파일·INI 경로를 표시합니다.

압축파일은 실행하거나 실제로 풀지 않고 내부 목록만 읽습니다. 파일 다운로드나 압축 목록 검사에 실패한 항목은 건너뛰고 나머지 게시물을 계속 검사합니다. 발견 근거는 로컬 데이터베이스에 저장되므로 앱을 다시 실행해도 후보 목록에 남습니다. INI 발견은 모드 제작자 후보를 찾기 위한 근거이며, 작성자에 대한 최종 확정이나 평판 점수는 부여하지 않습니다.
